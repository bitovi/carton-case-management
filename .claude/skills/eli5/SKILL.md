# ELI5 Skill

Explain the concept in simple terms, as if you were explaining it to a 5-year-old. 
- Use analogies and examples that a child would understand.
- Avoid technical jargon and complex language.
- Focus on the core idea and make it fun and engaging!
- Use the ask questions tool to clarify any details if needed before providing the explanation.

### 6.2.2 Implement Remaining Variants
#### 6.2.2.3 Verify and Fix All Variants

**Begin your response by outputting the heading lines above verbatim.**

Screenshot every variant in the component set, run a pixel diff for each, analyze all three images (React reference, Figma result, diff) to identify exactly what is different, then fix any issues. This is a combined verify+fix agent — it does both in one pass.

## Procedure

### 1. Screenshot every variant and build verify-manifest.json

For each variant listed in `figma-result.md`:

Use the Figma MCP `get_screenshot` tool:
- `fileKey`: from input
- `nodeId`: variant's node ID (not the set ID)
- Get at 2x scale

The `get_screenshot` response includes an asset URL (e.g. `https://www.figma.com/api/mcp/asset/{id}`).

**Determine the React reference screenshot** for each variant. Read the variant table in `figma-result.md` and match each variant to its corresponding React screenshot in `screenshots/`. The naming convention is typically `{ExportName}.png` from the story file.

After calling `get_screenshot` for ALL variants, write a single `verify-manifest.json` to `{componentDir}/`:

```json
{
  "componentName": "Badge",
  "componentDir": ".temp/react-to-figma/components/Badge",
  "variants": [
    {
      "name": "PrimaryDefault",
      "nodeId": "103:2",
      "assetUrl": "https://www.figma.com/api/mcp/asset/...",
      "reactScreenshot": "screenshots/PrimaryDefault.png"
    },
    {
      "name": "SecondaryDefault",
      "nodeId": "105:8",
      "assetUrl": "https://www.figma.com/api/mcp/asset/...",
      "reactScreenshot": "screenshots/SecondaryDefault.png"
    }
  ]
}
```

### 2. Run the batch verification script

Run ONE command that downloads all Figma PNGs, diffs them against React references, and writes consolidated results:

```bash
node .claude/skills/react-to-figma/6-get-component-context-and-implement-in-figma/2-implement-in-figma/scripts/verify-variants.js \
  --manifest "{componentDir}/verify-manifest.json"
```

This script:
1. Downloads each variant's Figma PNG to `{componentDir}/figma-variants/{name}.png`
2. Runs `compare.js` on each pair (React ref vs Figma PNG)
3. Writes diff images to `{componentDir}/diffs/{name}/diff.png`
4. Writes a consolidated `{componentDir}/verification-results.json`

**Check the exit code**:
- `0` = all pass
- `1` = minor diffs (some variants have small pixel differences)
- `2` = failures (some variants have significant differences)
- `3` = error (script failure)

### 3. Read results and analyze failures

Read `{componentDir}/verification-results.json`. For any variant with status `fail` or `minor_diff`:

View all three images for that variant:
1. `screenshots/{reactScreenshot}` — React reference
2. `figma-variants/{name}.png` — Figma result
3. `diffs/{name}/diff.png` — Pixel diff (red = different)

Use the diff image as a guide: red regions tell you exactly **where** differences are. Then inspect the React reference and Figma result at those regions to understand **what** is different.

For each red region, identify:
- Which visual element is it? (background, border, text, icon, spacing gap, shadow...)
- What does the React reference show? (color, shape, content)
- What does the Figma result show instead?
- Which Figma node is responsible?

### 4. Fix broken variants

For any variant with differences identified in step 3:

**a) Identify the variant's node ID** from `figma-result.md`

**b) Navigate to the specific node** within that variant:
```javascript
const variant = figma.getNodeById('{variantNodeId}');
const problemNode = variant.findOne(n => n.name === '{nodeName}');
```

**c) Apply targeted fixes** based on what the three-image analysis found:

```javascript
// Color fix:
const figmaVar = await figma.variables.getVariableByIdAsync('{variableId}');
problemNode.fills = [{ type: 'SOLID', color: { r: 0, g: 0, b: 0 } }];
problemNode.setBoundVariable('fills', 0, figmaVar);

// Text fix:
await figma.loadFontAsync(problemNode.fontName);
problemNode.characters = '{correctText}';

// Sizing fix:
problemNode.layoutSizingHorizontal = 'FILL';
fixSizing(variant);

// Visibility fix:
const hiddenChild = variant.findOne(n => n.name === '{name}');
hiddenChild.visible = false;
```

**d) Re-verify fixed variants**: After fixing, re-screenshot the fixed variants via `get_screenshot`, update `verify-manifest.json` with the new asset URLs (or write a `verify-manifest-fixed.json` with just the fixed variants), and re-run the batch script:

```bash
node .claude/skills/react-to-figma/6-get-component-context-and-implement-in-figma/2-implement-in-figma/scripts/verify-variants.js \
  --manifest "{componentDir}/verify-manifest-fixed.json"
```

View the new diff images to confirm fixes worked.

### 5. Verify component set structure

After individual variants are verified/fixed, check the set level:

```javascript
const set = figma.getNodeById('{setNodeId}');
return JSON.stringify({
  type: set.type,
  name: set.name,
  childCount: set.children.length,
  variantNames: set.children.map(c => c.name),
  layoutMode: set.layoutMode,
  width: set.width,
  height: set.height
});
```

Verify:
- Set type is `COMPONENT_SET`
- All expected variants are present (count matches `figma-result.md`)
- Variant names use correct `axis=value` format
- Set has auto-layout (not collapsed)

## Verdict Rules

| Verdict | Criteria |
|---------|----------|
| **PASS** | All variants pass or were successfully fixed. |
| **PARTIAL** | Most variants pass. 1-2 variants have minor issues that couldn't be auto-fixed (wrong icon that doesn't exist, complex structural difference). |
| **FAIL** | Multiple variants have unfixable issues, or the component set structure is broken. |

## Re-Run Behavior

This agent may be called again if the orchestrator receives PARTIAL or FAIL. On subsequent runs:
1. Read the existing `verification.md` for context on previous issues
2. Focus only on variants that were FAIL in the previous run
3. Try alternative fix approaches if the same fix was already attempted
